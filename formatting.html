Formatting HTML

This page is to demonstrate how to format texts using html tags via practical application.

DOCTYPE

!DOCTYPE declares the document type of the file.

HTML

HTML<HTML> stands for HyperText Markup Language and wraps the content of the web page.

HEAD

HEAD<head> holds metadata like the title tag.

META

META<meta> stores metadata about the HTML document.

TITLE

TITLE<title> defines the title of the webpage.

BODY

BODY<title> defines the main content of the HTML page.

BOLD

BOLD<b> makes the text bold.

STRONG

STRONG<strong> makes the text bold and tells the screen readers the text is important.

ITALIC

ITALIC<i> makes the text italic.

EMPHASIS

EMPHASIS<em> makes the text italic and adds emphasis.

UNDERLINE

UNDERLINE<u> underlines the text.

SMALL

SMALL<small> makes the text smaller than the surrounding text.

DELETE

DELETE<del> puts a strikethrough line over the text to show it was deleted.

INSERT

INSERT<ins> Underlines text to show it was inderted/added to the page.

SUBSCRIPT

SUBSCRIPT<sub> Lowers the text to create a subscript

SUPERSCRIPT

SUPERSCRIPT<sup> Raises the text to create a superscript.
